## Bugs / Errors Discovered
### Bug #10 — Python List Hashability TypeError in Service Loop
- **Date**: 16-Aug-2026
- **Symptoms**: Service loop crashed with `TypeError: unhashable type: 'list'` when indexing timeframe cache.
- **Root Cause**: Timeframe lists `['5m', '15m']` were used directly as dictionary keys.
- **Fix**: Converted timeframe lists to immutable tuples/strings before key access.
- **Commit**: `8e0c165`
- **Status**: ✅ **Resolved**

### Bug #11 — Render US Region Geo-Blocking (HTTP 451 / 403)
- **Date**: 16-Aug-2026
- **Symptoms**: Live trading container crashed on Render with HTTP 451 Unavailable For Legal Reasons when connecting to Binance Testnet.
- **Root Cause**: Render default deployments were in US regions (Oregon/Ohio), which are geo-blocked by Binance Spot API.
- **Fix**: Added `render.yaml` pinning deployment strictly to Frankfurt (`region: frankfurt`).
- **Commit**: `92e779e` / `da7937b`
- **Status**: ✅ **Resolved**

### Bug #12 — Docker Entrypoint Windows CRLF Line Ending Crash
- **Date**: 16-Aug-2026
- **Symptoms**: Container startup failed with `/bin/sh^M: bad interpreter: No such file or directory`.
- **Root Cause**: Shell scripts contained Windows CRLF line endings.
- **Fix**: Converted all shell scripts to Unix LF line endings.
- **Commit**: `e81ffa9`
- **Status**: ✅ **Resolved**

### Bug #13 — Realized PnL Double-Counting in Portfolio State
- **Date**: 16-Aug-2026
- **Symptoms**: Total account equity artificially inflated upon trade close.
- **Root Cause**: Realized profit was added to cash balance while also being summed into total equity.
- **Fix**: Enforced strict formula `Total Equity = Cash + Crypto Holdings`.
- **Commit**: `6aeb104`
- **Status**: ✅ **Resolved**

### Bug #14 — Duplicate Exit Order ID Ledger Pollution
- **Date**: 16-Aug-2026
- **Symptoms**: Partial order fills recorded duplicate trade close events in ledger.
- **Root Cause**: Missing order fill deduplication map.
- **Fix**: Implemented key-based exit order deduplication in `_get_trades_data()`.
- **Commit**: `6aeb104`
- **Status**: ✅ **Resolved**

### Bug #15 — Reconciliation Lock Thread Blocking
- **Date**: 16-Aug-2026
- **Symptoms**: Strategy evaluation loop stalled during periodic portfolio reconciliation audits.
- **Root Cause**: Synchronous balance query held global lock.
