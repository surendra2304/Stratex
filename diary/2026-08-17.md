## Bugs / Errors Discovered
### Bug #16 — Missing Key 500 Internal Server Error in `/api/scanner`
- **Date**: 17-Aug-2026
- **Symptoms**: Scanner view failed with HTTP 500 when Binance returned incomplete ticker dict.
- **Root Cause**: Unchecked dictionary indexing on optional ticker fields.
- **Fix**: Replaced raw indexing with defensive `.get()` lookups and sensible fallbacks.
- **Commit**: `ef7d88f` / `0f7f5c7`
- **Status**: ✅ **Resolved**

### Bug #17 — Trading Engine Stall During Quiet Market Hours
- **Date**: 17-Aug-2026
- **Symptoms**: Bot stopped evaluating signals when low-volume pairs stopped producing 1m candle close events.
- **Root Cause**: Event loop blocked waiting synchronously on incoming WebSocket klines.
- **Fix**: Added timer-based tick staleness watchdog with automated REST polling fallback.
- **Commit**: `ff8bd69`
- **Status**: ✅ **Resolved**

### Bug #18 — Heartbeat Serialization Crash on Datetime Objects
- **Date**: 17-Aug-2026
- **Symptoms**: Supervisor failed to parse `heartbeat.json` due to un-serialized `datetime.datetime` object.
- **Root Cause**: `json.dump()` called on non-primitive datetime object.
- **Fix**: Converted all heartbeat timestamps to ISO 8601 strings prior to disk write.
- **Commit**: `ff8bd69`
- **Status**: ✅ **Resolved**

### Bug #19 — JavaScript TypeError on Inactive Dashboard Tabs
- **Date**: 17-Aug-2026
- **Symptoms**: Polling loop threw console exceptions when updating DOM elements on hidden tabs.
- **Root Cause**: `document.getElementById()` returned `null` for unrendered elements.
- **Fix**: Added `safeSetText()` null guards across all DOM updater functions.
- **Commit**: `bd171ad`
- **Status**: ✅ **Resolved**
