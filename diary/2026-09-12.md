## Bugs I Found & Fixed
- **ExecutionPolicy Module-Level Import Invalidation**: `execution.py` imported static config values at top-level; refactored to dynamic getattr to honor config overrides.
- **Config Validation Regex Ordering**: `validate_config()` checked environment safety before mode enum, breaking existing tests; reordered to satisfy both validations.
- **Inference Order Injection Vector**: Raw responses from advisory endpoints could potentially include order actions; added strict sanitizer stripping all execution directives.
- **Drawdown Sign Discrepancy**: Drawdown percentage checks failed if reported as positive or negative; added absolute value normalization before threshold evaluation.
- **Advisory Staging State Overwrite**: Parameter updates were previously applied immediately; introduced intermediate staging queue requiring explicit authorization token.
- **Clock Skew System Drift**: Added mockable time provider to clock skew verification to ensure deterministic testing without real-time drift.

## Key Decisions & Architecture
- Enforced invariant: Inference is strictly advisory, Stratex holds deterministic execution authority, and live real-money trading is permanently disabled.
- Decoupled advisory generation from parameter application using explicit cryptographic tokens and multi-party authorization protocols.
- Structured all audit events into a SHA-256 chained JSONL ledger providing non-repudiation for all automated and operator interventions.
- Isolated testnet and paper execution environments with complete gate enforcement on every single order attempt.
