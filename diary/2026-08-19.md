## Bugs I Fixed

**Bug #35 — HTML Structural Corruption from Sequential Replacement Scripts**
Executing sequential search-and-replace scripts damaged DOM parent-child tag relationships in `index.html`. I resolved this permanently by writing `build_full_ui.py`, which compiles all 10 views from clean template constants in a single pass. Resolved ✅

**Bug #36 — Missing /api/config Endpoint and apiClient.post Method**
The Settings page UI attempted to save configuration to `/api/config`, but the route did not exist in `dashboard.py` and `apiClient` only supported GET requests. I created the `/api/config` route and implemented `apiClient.post()` with JSON serialization. Resolved ✅

**Bug #37 — Polling Contention and View Switching Routing Mismatch**
Tab navigation listeners referenced obsolete view IDs, causing `fastPoll()` to query every endpoint simultaneously on every clock cycle. I mapped tab listeners to the 10 approved view IDs and routed polling dynamically to the active view only. Resolved ✅

**Bug #38 — Frontend JS Syntax Error on Duplicate Variable Declaration**
`app.js` contained duplicate variable declarations that halted browser script execution. I cleaned up the global scope, added URL hash routing for direct view linking, and restricted CORS origins to authorized hosts. Resolved ✅
