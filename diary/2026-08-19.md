## Bugs / Errors Discovered
- **Bug #35**: `index.html` structural corruption from sequential replacement script execution causing DOM tag mismatches.
  - Root Cause: Consecutive `rewrite_*.py` scripts overwritten markers inside each other's view containers.
  - Fix: Developed `build_full_ui.py` to compile the views explicitly from constant template strings.
  - Verification: 100% structure validation with zero missing DOM tags.
- **Bug #36**: Missing `/api/config` backend endpoint and `apiClient.post` client method in settings control layer.
  - Root Cause: Settings page UI called `/api/config` for GET/POST but endpoint wasn't defined on Flask backend, and `apiClient` only implemented `.get()`.
  - Fix: Implemented safe `/api/config` endpoint in `dashboard.py` and added `post()` method with JSON body serialization to `apiClient` in `static/app.js`.
  - Verification: GET /api/config returns 200 with active configuration; settings save POST verified.
- **Bug #37**: Polling contention and view switching routing mismatch in `static/app.js`.
  - Root Cause: Navigation tab clicks referenced legacy view IDs (`signals`, `market`, `activity`) rather than active 10 views (`scanner`, `markets`, `system`, `positions`, `settings`), and `fastPoll()` was blindly querying all views on every tick.
  - Fix: Updated tab click routing to exact 10 view handlers and added intelligent active-view routing in `fastPoll()`.
  - Verification: View navigation transitions instantly and polls only active view data.
- **Bug #38**: Frontend JS syntax error on duplicate `let activeMarketSymbol` declaration, live trading execution path removal, and CORS origin restriction.
  - Root Cause: Duplicate variable declaration halted JS evaluation on client load; live Binance client creation path remained dormant in `execution.py`; CORS allowed wildcard origins.
  - Fix: Removed duplicate variable, added URL hash routing, permanently blocked live execution by design, restricted CORS to Frankfurt Render & local dev origins, and added `/api/config` input validation.
  - Verification: `node -c static/app.js` passed, 421/421 tests passed across 2 runs, production endpoints verified.
