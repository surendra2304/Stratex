### Bug #07 — Dashboard Frontend Crash on Missing / Null Win Rates
- **Date**: 15-Aug-2026
- **Symptoms**: JavaScript exception `TypeError: Cannot read properties of undefined (reading 'toFixed')` broke dashboard updates.
- **Root Cause**: Unpopulated strategies had `win_rate: null`.
- **Fix**: Added safe null-coalescing wrappers `safeSetText()` in `static/app.js`.
- **Commit**: `b4d638a`
- **Status**: ✅ **Resolved**

### Bug #08 — Telemetry Cross-Contamination Across Sessions
- **Date**: 15-Aug-2026
- **Symptoms**: New test sessions aggregated trades from old discontinued sessions.
- **Root Cause**: Telemetry manager lacked session ID filtering.
- **Fix**: Enforced mandatory `session_id` tagging and filtering across all ledger readers.
- **Commit**: `ecc0e56`
- **Status**: ✅ **Resolved**

### Bug #09 — Statistical Sample Size Logic Flaw in Dual Gate
- **Date**: 15-Aug-2026
- **Symptoms**: Strategy passed forward gate after only 2 trades if duration was 30 days.
- **Root Cause**: Gate evaluated `duration >= 30 OR trades >= 30` instead of `AND`.
- **Fix**: Changed conditional to require `duration_days >= 30 and trades >= 30`.
- **Commit**: `28e7cc7`
- **Status**: ✅ **Resolved**
