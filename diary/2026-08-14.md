## Bugs / Errors Discovered
### Bug #01 — Windows Console UTF-8 UnicodeEncodeError
- **Date**: 14-Aug-2026
- **Symptoms**: Dashboard startup failed with `UnicodeEncodeError: 'charmap' codec can't encode characters` on Windows PowerShell console.
- **Root Cause**: PowerShell `cp1252` encoding failed on UTF-8 currency and emoji symbols.
- **Fix**: Wrapped standard output stream with `io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')`.
- **Commit**: `82883cc`
- **Status**: ✅ **Resolved**

### Bug #02 — Binance Spot OCO Parameter Rejection (HTTP 400)
- **Date**: 14-Aug-2026
- **Symptoms**: Binance Testnet rejected bracket orders with HTTP 400 Bad Request.
- **Root Cause**: Invalid order parameter type (`STOP_LOSS` vs `STOP_LOSS_LIMIT`) in Spot API payload.
- **Fix**: Replaced raw stop loss with `STOP_LOSS_LIMIT` specifying valid `stopPrice` and `price`.
- **Commit**: `64452f0`
- **Status**: ✅ **Resolved**

### Bug #03 — ML Feature Calculation Lookahead Bias
- **Date**: 14-Aug-2026
- **Symptoms**: ML backtest exhibited unrealistic 85%+ win rates due to label leakage.
- **Root Cause**: Features were normalized across entire dataset prior to train/test split.
- **Fix**: Shifted all feature arrays by 1 period ($t-1$) and restricted scaling to past window.
- **Commit**: `237045e`
- **Status**: ✅ **Resolved**

### Bug #04 — Execution Friction Underestimation
- **Date**: 14-Aug-2026
- **Symptoms**: Low-edge trades generated net losses due to exchange fees.
- **Root Cause**: Zero-fee and zero-slippage assumptions in signal generator.
- **Fix**: Implemented `CostEngine` requiring `expected_gross > 0.31%` before dispatching signals.
- **Commit**: `4090682`
- **Status**: ✅ **Resolved**

### Bug #05 — API Credential Leakage in Public Client
- **Date**: 14-Aug-2026
- **Symptoms**: Authenticated Binance client was being used for public candle data queries.
- **Root Cause**: Monolithic client architecture.
- **Fix**: Decoupled public `MarketDataClient` from private `ExecutionClient`.
- **Commit**: `1023495`
- **Status**: ✅ **Resolved**
